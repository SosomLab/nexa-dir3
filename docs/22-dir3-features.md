# 22 · dir3 신규 기능(dir2에 없음) — NEW 원장

> 작성 2026-10-03. **dir2에 없는 기능**(사용자 지시로 dir3에 새로 넣는 것)의 원장이다. dir2 이식 원장([port/](port/00-index.md))과 구분한다 — port는 "dir2를 그대로", 이 문서는 "dir3에서 새로".
> ID 접두 **NEW-NNN**(번호는 한 줄로 늘어난다 · 재번호 금지). 결정은 [10](10-decision-record.md) DR-15~23. 할 일은 [TODO](TODO.md) T-92~T-102.
> 상태: ☐ 미착수 · 📐 설계 · 🚧 진행 · ✅ 구현+시험. `scripts/matrix-audit.py`가 이 표의 `NEW-NNN`도 원장으로 읽는다 → 검증 매트릭스([port/90](port/90-verification-matrix.md))에 NEW 행을 걸어야 "미착수"가 0이 된다(상태는 매트릭스 행과 이 표를 같이 고친다).
