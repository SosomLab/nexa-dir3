# 22 · dir3 신규 기능(dir2에 없음) — NEW 원장

> 작성 2026-10-03. **dir2에 없는 기능**(사용자 지시로 dir3에 새로 넣는 것)의 원장이다. dir2 이식 원장([port/](port/00-index.md))과 구분한다 — port는 "dir2를 그대로", 이 문서는 "dir3에서 새로".
