Nexa Dir 0.30.2 — fixes macOS copies that never finished on a full disk, and adds a dialog focus option for window transparency

Fixes since 0.30.1:
- macOS: copying or moving onto a volume that ran out of space (or hit another write error) never finished — the transfer stalled at high CPU and could only be cancelled. The error is now reported and the item fails like on other systems (GAP-049).
- macOS: application bundles (.app) showed "96 B" in the size column before their folder size was calculated. The cell now stays empty until the size is known, like a folder (GAP-050).

New setting:
- Appearance → "Keep the main window active while a dialog is open" (window.dialog_keeps_active, on by default). On keeps the current behavior: while one of Nexa Dir's own dialogs (modal or modeless) has focus, the main window keeps its focused transparency. Off treats the main window as inactive as soon as a dialog takes focus, so the unfocused transparency applies.

Behavior changes:
- Window transparency defaults: focused 0 % → 5 %, unfocused 20 % → 10 %. Values you already changed in settings are kept; only the defaults move.

Packages: Windows MSI + portable zip, macOS Universal pkg/dmg, Linux deb/rpm (also via winget, Chocolatey, Homebrew tap and pkg.sosomlab.com). Channels whose previous submission is still under review are skipped automatically and submitted later.
